# DataGuard editorial audit workspace — design system

Generated and inspected before implementation: `editorial-overview-concept.png`, `editorial-agent-concept.png` (built-in Image Gen). Adopted autonomously within the requested direction; no approval pause was requested.

Direction: institutional audit journal with generous warm ivory negative space, deep forest navigation and audit ledger, chartreuse actions and muted gold evidence rules. Keep all thirteen routes and actual API state. Never invent counters, historical activity or model answers.

Tokens: canvas #f6f3e9, paper #fffef9, forest #143d32, ink #17251f, muted #68716a, line #dcdccf, chartreuse #d7e78a, gold #a5843b, alert #a85740. Spacing 4/8/12/16/24/32/48/64. Radius 4/6/8. Quiet shadows restricted to overlays.

Typography: Instrument Serif for brand, page titles (64px desktop / 44px mobile), section display (32px), ledger figures (72px); Manrope for navigation, body, forms, tables, buttons and captions (12–15px). Monospace only for record IDs, hashes, JSON and code. Self-hosted fonts if available; Georgia and system UI fallbacks.

Families: forest shell and grouped nav, serif editorial page header, horizontal audit ledger with four actual figures and source→capture→checks→publication chain, fine-rule source register, actual check matrices, evidence rail, chronological capture journal, policy form, comparison worksheet, source-detail drawer, question→findings→evidence investigation sheet. No decorative data trends or repeated metric-card grids.

Primary copy locked from concepts: Trust is built on evidence. / Eight public repositories. One inspectable chain of trust. / Export evidence / Investigate data / Source register / Every result has a source. / Ask the evidence. / Real questions. Public GitHub records. A visible trail of reasoning. / What would you like to investigate? / Investigate public data / Your source material / Grounded, step by step.

Controls and workflow: repository search, sort and archived/licensing filters; record drawer with exact fields and source links; linked investigation across data, checks and lineage; Markdown findings rendered through safe DOM with source-citation actions; existing public quotas and countdown; operator forms unchanged in authorization and API semantics. Mobile navigation includes expanded state, Escape/outside close and focus restoration. All interactions respect keyboard use and reduced motion.

Color/background and main architecture follow the concepts. Actual API timestamps and row contents take precedence over incidental generated dates. No raster is embedded as interactive UI; all controls, records, charts and diagrams remain code native. Root owns CUA verification and supplies rendered screenshots for concept comparison.
