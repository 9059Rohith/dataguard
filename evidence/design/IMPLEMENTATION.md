# Editorial workspace implementation and verification

The two Image Gen concepts in this directory were generated and inspected before implementation. The design system is recorded in DESIGN.md.

Implemented across all thirteen routes: a forest-and-ivory app shell, self-hosted Instrument Serif and Manrope, consistent fine-line SVG icons, editorial display headings, larger readable controls and data text, thin-rule tables, quiet gold evidence accents and chartreuse actions. The overview follows the concept's audit ledger and source→capture→contract→publication chain, then the source register and provenance rail. All displayed counts, timestamps and source values come from the existing API.

The investigator follows the question→findings→evidence concept. The form remains token-free and preserves the existing quotas and cooldown. The initial state has no invented model answer. Actual answers are rendered through safe DOM nodes, supporting headings, bold, code, lists, tables, HTTPS/HTTP source links and capture-reference buttons. Active HTML and unsafe links are rendered as text or rejected; model text never enters innerHTML. Source citations open the actual capture drawer.

Source records now support real search, repository/stars/issues/update sorting, active/license/open-issue filters, an exact record detail drawer, raw source inspection, safe source links, and a record→checks/lineage/public-question workflow. Capture history has real text and status filters. Recorded checks have an actual-state overview matrix. Version comparisons use canonical nested object ordering. Private imports, notes, policy and recovery actions retain their existing authentication and API semantics.

Mobile navigation includes expanded state, an outside-close backdrop, Escape handling, focus containment/restoration and inert background content. Main content has a skip link. Native dialogs remain keyboard accessible. Reduced-motion rules disable transitions and smooth scrolling. Long digests, tool arguments, source metadata and tables use bounded wrapping or internal scrolling.

Only static asset GET routes and package-data entries were added to Python code. Public Gemini handlers, SQL rate buckets, authorization, origin checks, provider secrets and persisted source data were not changed or reset.
