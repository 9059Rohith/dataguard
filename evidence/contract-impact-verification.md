## Standards and performance scope

The exported OpenLineage dataset facet validates offline against the unmodified official
1-1-0 assertion schema and referenced 2-0-2 core schema. A negative control with string-valued
success fails validation. Disabled rules are omitted. This is a facet export, not a complete
lineage event or a running lineage integration.

[Measured benchmark](contract-impact-benchmark.json): 1,000 comparisons of the actual checked-in
eight-row capture and six rules per policy. Median **1.220 ms**, p95 **2.109 ms** on this Windows
Python 3.12 environment. The first lazy-import sample (**841.850 ms**) is included and disclosed.
These are local evaluator elapsed times; they do not measure database, network or HTTP latency
and are not a hosted-service SLO.

The workbench tests acceptance preferences against a captured sample. It does not infer software
quality, security, license suitability, future activity, or a representative ecosystem statistic.
Primary source links and the implementation decisions are in the
[design document](../docs/contract-impact-design.md).
